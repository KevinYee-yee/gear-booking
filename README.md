# 攝影器材管理與預約系統

公司內部器材庫存清點 + 跨部門線上申請借用。**申請制**：其他部門線上提申請 → 你審核 → 核准才鎖定時段，系統自動擋撞期。

## 架構
- `index.html` — 前端單檔（公開查詢 + 提申請；PIN 進管理端審核/增刪器材）
- `Code.gs` — Google Apps Script 後端 API
- 資料存在 Google Sheets（兩張表：器材、預約）

## 部署步驟（約 10 分鐘）

### 1. 建 Google Sheet
1. 開一個新的 Google 試算表，隨意命名（例：`器材資料庫`）
2. 上方選單 **擴充功能 → Apps Script**
3. 把 `Code.gs` 全部內容貼進去，覆蓋預設的 `myFunction`
4. **改 PIN**：把檔案最上面的 `var ADMIN_PIN = '1234';` 改成你要的密碼
5. 存檔

### 2. 一鍵初始化資料表
1. 在 Apps Script 編輯器上方，函式下拉選 `setupSheets`，按 **執行**
2. 第一次會要求授權 → 允許
3. 回試算表，會自動出現「器材」「預約」兩張表和三筆範例器材

### 3. 部署成 Web App
1. Apps Script 右上 **部署 → 新增部署作業**
2. 類型選 **網頁應用程式**
3. 「執行身分」= **我**；「誰可以存取」= **機構內任何人（凱羅斯健康）**
   - 只有公司同仁進得來，且系統會自動記下申請者的公司 email（防造假、可追人）
   - 若要開放給無公司帳號的外部廠商，才改成「任何人」（就只能靠表單自填姓名）
4. 部署 → 複製那串 **網頁應用程式網址**（`…/exec` 結尾）

### 4. 接上前端
1. 用瀏覽器打開 `index.html`
2. 第一次會提示設定 API 網址 → 貼上剛剛的 `/exec` 網址
3. 完成！之後網址記在瀏覽器 localStorage

> 想放到公司內部連結：把 `index.html` 丟上 GitHub Pages 或任何靜態空間即可（跟你其他 PWA 一樣）。

## 使用方式
- **其他部門**：開連結 → 器材庫存搜尋 → 「預約借用」填日期與資料 → 送出。可在「預約查詢」看狀態、取消。
- **你（管理端）**：右上「管理端」→ 輸入 PIN → 審核待辦（核准/拒絕）、登記歸還、逾期一目了然、增刪改器材。

## 撞期防護
- 送申請時：顯示該器材已核准的時段，並擋下與已核准區間重疊的申請
- 你核准時：再檢查一次，若期間已被其他核准案占用會擋下

## 之後可擴充
- Email/Slack 通知（申請送出、核准結果、逾期提醒）
- QR code 貼在器材上，掃碼直接開該器材預約
- 借還拍照存證、器材維修保養紀錄
